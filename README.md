# scholarship-app
A set of functions used to determine who deserves a scholarship.

Napisz czysty kod, który na podstawie danych studentów (moodle) obliczy średnią dla każdego studena, oraz posortuje studentów wg tej średniej, a następnie zwróci NIU studentów, którzy powinni otrzymać stypendium.

# Installation

1. Install Python 3.14 on your machine
2. Create `venv`, by `python -m venv .venv`
3. Activate `venv`, by `.venv\Scripts\activate` for Windows or `source .venv/bin/activate` for Unix-like OS.
4. Install required dependencies - `pip install -r requirements.txt`
5. Run the code `python -m main.py`.
